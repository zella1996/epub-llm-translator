状态：方案已实施；当前实现与验收结论见 [项目说明](../PROJECT.md)。本文保留设计理由和阶段计划。

## 1. 目标与决策原则

首要目标是帮助用户读懂并持续阅读自己想读的外文书籍；外文思维在阅读原书的过程中
锻炼，不另设训练任务。近期仍以英语为实际实现和验证对象，不因此扩大多语言开发范围。

这里的“外文思维”指沿原文的信息展开理解人物、事件、主线、限定与语气，而不只是
获得一份中文情节概述。辅助应让原文的表达更容易跟上，看懂后即可继续原书。需要中文
参考并不算失败；不要求只能用外文、不强制重读，也不设减少中文使用的指标。

本次 review 的结论：原方案把“理解原文”和“训练能力”并列，导致功能、阅读流程和
验收都加入了额外学习任务。现在删除练习、自检题、复述任务、新句迁移测试与复习安排，
不以“可选练习”的形式保留。教材只提供理解障碍与辅助方式的设计参照，不照搬课程活动。

用户允许调整此前规则，也能容忍模型错误。产品取舍首先看能否读懂并继续读、是否误导
或打断阅读，再比较辅助负担和运行成本；不以读得更快掩盖理解错误，也不要求每条内容
完美合规后才开展阅读验证。
本方案取代旧记录中“仅句意、固定双阶段、Stanza 必须保留、零语义错误”等产品限制。
旧记录保留其历史结论；预算、隐私、凭据保护与源文件安全继续按明确授权执行。

**推荐路线：段落语境下的一次主要生成，配合按需中文参考、局部释义与阅读提示，解除卡点后继续原书；
首版不引入自动追加复核，单次与双阶段先做对照。** 这是优先验证的候选，
不是已经证明的最优架构。保留旧方案作为可复现对照，不先进行全项目重写。

## 2. 从历史实验中保留下来的教训

| 试错记录 | 可以相信的经验 | 对新方案的影响 |
| --- | --- | --- |
| GLM 早期调优：保留全部代词使中文难读；收窄规则后仍出现编造亲属关系 | 格式保留不能保证理解正确；过度混合语言有代价 | 保留词是帮助识别的手段，允许中性译法或译名；重点评身份／关系是否误导 |
| 阅读可用性实验：解析器分数改善，尚无对应阅读收益；本地 selector 会丢掉正确关系 | 技术指标不能替代读者价值 | 先收集真实卡点，不先扩建 parser 或模型路由系统 |
| 结构提示试验：笼统的“修饰主语”不能帮助恢复长句主线 | 正确标签也可能无助于阅读 | 提示应说明如何继续读、在哪里回到主线，并指向实际英文 |
| 安全投影修复：拼主干会丢否定、情态和系词 | 精简可能改变原意 | 引用原文片段；必要成分保留，无法可靠压缩就显示完整原句 |
| quality 压缩实验：独立端到端运行混入 fast 随机变化；冻结后仍有筛选差异 | 少 tokens、少卡不等于等质 | 保存原始结果与各阶段选择，生成质量和选卡效果分别评估 |
| Gemini 阅读实验：用户认可主线辅助，重视贴序而不贴词 | 结构辅助并非被彻底否定 | 允许重新试验短顺读提示，不照搬旧四字段卡片 |
| [v2 与 literal 历史](structured-meaning-v2.md)、[v6 记录](literal-meaning-baseline.md)：讲解膨胀、习语字面化、规则叠加后无 meaning、跨轮波动 | 指令更长或更短都不能保证更好 | 用短任务定义起步，按真实失败修改；未显示收益的规则不继续叠加 |
| 重设计前技术基线：双阶段同模型同 max；段译不接受 quality 修订；整章只做了六卡阅读抽样 | 架构能运行，不等于更省或更有助学习 | 先补单次生成对照；不用整章技术通过代替实际阅读验收 |

上表数字、参数与成功／失败均属于对应历史记录，不作为新实验的当前供应商参数。

## 3. 第一版想让读者得到什么

保留英文作为主要阅读材料。正常路径是：**读原书 → 遇到卡点时查看帮助 → 看懂后继续
原书**。不要求先猜答案、按层解锁译文、证明理解或完成任何任务才能继续。
以下是按需阅读功能，不必永久固化成模型 JSON 字段，也不要求每句全部生成。

| 功能 | 内容 | 何时值得出现 |
| --- | --- | --- |
| 连续理解 | 忠实、可读的中文参考，照顾当前段落的衔接 | 用户需要确认发生了什么；已有段译足够时不重复解释 |
| 局部释义 | 引用实际短语，说明当前语境中的词义、习语或搭配 | 卡点局部即可解决，不必翻译整句 |
| 句子提示 | 共享句译、指向英文的简短解释，或两者结合 | 意义不清或跟不上表达时提供；不强制两者成套 |
| 段落衔接提示 | 有证据的转折、照应或信息推进说明 | 仅在跨句关系仍不清楚时补充，不重复段译或固定写段落摘要 |

这吸收 Fable 按困难位置提供帮助的思路，但不采用“译文必须降级”“注释越少越好”
或固定数量配额。已有段译位于章末按需辅助区，不是正文旁的平行译文；用户主动打开
帮助后可以直接看译文，无需再点击一次。三种提示是可选内容，不是三个独立调用阶段。

首版沿用段末入口，短语释义也先放在辅助区，不承诺正文词级弹窗。所选章节内支持的
正文段落默认预生成译文；“按需”是按需查看，不是在 Kindle 上临时调用模型。
显式开启本地跳过时不能保证每段有兜底，具体覆盖与预算取舍见技术方案。

词义、习语或指代造成卡点时，可就原书当前表达给出简短释义，不另造练习例句。
英文释义应比原句容易，否则可用简短中文说明；不要求每句都附英文改写。
语法术语、背景说明、段落功能分析都允许使用，但只在有助于读懂当前内容时出现，
不因某个结构“值得学习”就出卡。合理的上下文推断可以帮助理解；需要时区分原文
明确内容与推测，不把无法确定的信息硬补成事实。

自拟示意（不是模型实测结果）：

> Mara, who had expected an immediate reply, did not open the envelope until the next morning.
>
> 顺读：先记住 Mara；中间补充她原以为会立刻收到回复；读到 did not open 时回到主线，
> until the next morning 才给出时间边界。
>
> 中文参考：Mara 原以为会立刻收到回复；她直到第二天早上才打开那个信封。

顺读提示不再给出第二份完整译文；它帮助跟上当前原句，看懂即可继续后文，没有附加
问题。这个例子只示范方向，不能证明这样展示一定优于当前卡片；先制作少量对照页面。

## 4. 推荐的最小生成架构

当前段落与稳定句索引 → 一次主要生成逐句译文与可选提示 → 本地验证 →
版本化共享结果 → 派生段译与章末辅助。单次生成先与同最终契约的两阶段候选对照，
首版不先开发语义风险路由或自动复核。

保留完整句译映射；提示的作用范围可以是短语、句子或当前段落。原文由本地索引绑定，
额外提示没有价值时允许为空。Stanza 首轮固定证据，后续再比较移除是否影响结果。

具体契约、部分提示失败的处理、离线译文覆盖、成本和缓存身份见
[技术方案](reading-assistance-implementation-plan.md#4-最小数据契约)，不在本文件重复定义。

## 5. 放宽哪些规则，怎样容忍错误

| 曾使用的约束或策略 | 新处理 |
| --- | --- |
| 只能输出 meaning，不能讲解 | 允许帮助读懂当前原文的短提示与释义；不强制填满栏目，不加入练习 |
| quality 只接收候选句 | 首版用当前段落；确有需要时试验授权范围内的邻段 |
| 固定 fast → quality 流程 | 用单次完成作基线；额外调用需证明收益 |
| Stanza 永远必需 | 对照评估后保留、缩小范围或移除 |
| 姓名、称谓必须逐字保留 | 默认方便识别；身份不混淆时允许自然译法，含糊关系可用原词或中性表达 |
| 40 词门槛和固定密度决定卡片 | 旧基线保留供比较；新路径按实际卡点提供短语／短句提示，不按旧长句门槛删除 |
| 一处语义错误或未满分即整组失败 | 记录错误的实际影响，比较总体帮助与负担；个别错误不自动否定整个方向 |
| 最小 prompt、研发轮次零重试 | 简洁是起点；按收益增删指令。重试可以有，但必须有上限、保留失败且计入预算 |

错误按影响处理，而不是只看是否命中禁词：

- **可直接接受的瑕疵：**局部生硬、无害的译名格式差异、轻微啰嗦。先记录，不为此停止阅读。
- **有帮助但需注意：**细微词义或语气偏差、不够稳妥的推断、冗余提示。可继续使用，
  在评价中指出；系统能可靠识别时才给局部提醒，不声称能自动检测所有错误。
- **明显误导：**教反否定、持续混淆人物、虚构关键因果。单列影响与实例，优先修复；
  个别案例不自动触发无限重试，若同类错误反复出现，则暂缓扩大使用或调整该功能。
- **技术不可用：**索引错配、内容截断无法解析、原文被误改或凭据泄漏风险。
  阻止受影响结果冒充成功；保留已有进度，按明确策略停止或提示该段辅助缺失。

允许错误不等于把猜测写成确定结论，也不等于把评价结果美化。用户可以基于已说明的
风险选择更有帮助的版本；阅读辅助不被视为原文之外的事实权威。

## 6. 分步实施与退出条件

执行 [技术方案的 P0–P4](reading-assistance-implementation-plan.md#6-实施顺序与退出条件)：
先修复影响比较的程序缺陷，再打通纯文本新契约与调用对照，随后验证 EPUB 展示，
最后接入 CLI、缓存和章节运行。每一步都有独立出口；弹窗、邻段语境和自动复核后置。

该顺序取代此前“模型实验后直接连续阅读”的简略安排，补上离线覆盖、版本缓存、
预算和源文件／导航验收。模型样例测试由开发侧承担，用户按自己的节奏阅读、自愿反馈。
实机未测试或没有阅读反馈时分别标记待验收，不用技术通过代替阅读收益。

## 7. 验收看什么

| 维度 | 观察方式 | 如何影响决定 |
| --- | --- | --- |
| 连续阅读 | 查看帮助后是否能继续原书，是否频繁被辅助拖离内容 | 首要收益；不把读速或读完页数当作唯一指标 |
| 当下理解 | 用户反馈卡点是否解除；开发侧核对事实、关系与语气 | 连续阅读不能以反复误解内容为代价 |
| 原文对应 | 译文、释义与提示是否指向当前原句，是否帮助跟上信息展开 | 支持在阅读中理解外文表达；不要求隐藏中文后讲解结构 |
| 阅读负担 | 提示长度、重复解释、跳转与返回是否妨碍阅读 | 帮助相近时优先负担小的方案；不设置打卡、评分或中文使用配额 |
| 错误成本 | 按实际影响记录错误、纠正时间及重复模式 | 不要求零错误，也不能用平均分隐藏反复误导 |
| 运行成本 | 完整任务的实际 input／completion／reasoning、延迟、失败重试 | 帮助更大可接受较高成本；第二次调用须有可指出的收益 |

无需预设“必须 7/8”“100% 专名保留”或固定通过率。开发侧写清本轮要解决的问题，
展示成功与失败；用户按自然阅读体验取舍，不需要交验收作业。结果相近时选择简单、
便于恢复的方案；需要更多证据时再补开发样例或等待自愿阅读反馈，不改分数来宣布胜出。

外文思维是长期设计方向，不另设能力考核。后续自然阅读中感觉更容易跟上原文，只能
作为个人体验信号；少点击帮助、读得快或少看中文，都不能单独证明理解或能力提升。
不为验证这个目标新增阅读行为追踪或自动学习评分。

## 9. 外部研究如何参与判断

英文教材及阅读机构资料见 [教材评审](reading-design-review-2026-08-28.md)。本方案借鉴
语境线索、理解障碍分类与按需辅助；教材中的课堂练习、应用与复习安排不进入产品。
这些资料不决定必须有几个模型调用或几个卡片字段，也未证明本工具的长期阅读效果。

FrugalGPT 展示了按查询选择模型组合的成本／质量潜力；本项目据此把第二阶段视为
需要验证的策略，不移植论文的收益数字。[FrugalGPT 原论文](https://arxiv.org/abs/2305.05176)

2026 年的文学翻译研究比较了不同生成与修订粒度，在其设置中全文生成后做片段级修订有优势，但
收益主要来自流畅度、忠实度提升较有限。本项目据此分别评中文可读和原文理解，不把
二次改写自动视为学习提升。[ACL 2026 文学翻译研究](https://aclanthology.org/2026.acl-long.268/)

这些均为英文原始资料；没有新增简体中文网络语料。应用到本工具的方案是待检验推论，
不是论文或教材已经替我们完成的验证。
