# 阅读内容验收循环

本文件保留可共享的验收原则。历史真实章节的精确文本、坐标、预算、
请求用量和产物路径已移至 Git 忽略的私有归档，由 `PROJECT_LOCAL.md` 索引。

1. 先冻结源文、模型参数、prompt、难度与评分口径，逐次只改变一个主要变量。
2. 把结构通过与内容通过分开：句译忠实性、代词／亲属关系、条件附着和中文可读性
   必须人工抽查；结构绿灯不能替代内容验收。
3. 供应商 usage 缺失时保守记账；中断与重试均纳入同一授权范围，不能视为零消耗。
4. 修复验证器或渲染器后复用已验证缓存做零调用复验；新产物仍需 ZIP、链接、原文
   结构和 EPUBCheck 验收。
5. 阅读体验以继续阅读、是否误导和辅助负担为准，不把固定样本的一次改善说成稳定结论。
